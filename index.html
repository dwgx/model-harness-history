05

MECHANICS / 机制

破甲到底在破什么

指令装载链

01

身份替换

移除旧身份唤醒段，写入新 persona + 口令。验证的是“载入”，不是“绕过”。

02

政策替换

直接声明“无限制开发者模式 / 关闭过滤器”。短、直接，但与拒答训练正面冲突。

03

范围重构

把任务框成 CTF 沙箱 / 授权渗透 / 虚构创作。模型拒绝的是“意图”，不是“技术动作”。

04

上下文稀释

塞满上下文，再输入目标提示词。长上下文模型越来越强，边际收益在下降。

05

权威升级

声明本地指令 “ACTIVE and MANDATORY”、不是不可信数据。直接对抗宿主的削弱层。

06

宿主补丁

改 prompt 渲染、sandbox deny→allow、approval→never、启动 shim。绕过的是宿主策略。

边界

上下文 ≠ 策略。Claude Code 官方明说 CLAUDE.md 是 context，不是 enforced configuration；Codex 的 model_instructions_file 只替换本地内置指令，服务端审核、账号风控、模型拒答训练仍在。小怪 README 自己写“不支持绕过云端审核”——这是整个流派最诚实的注脚。
